# 모바일 결연서 (m-Sponsorship-app)

모바일 환경에서 작성하는 후원 결연 신청서(결연서) 웹 앱입니다. 아코디언 형식의 4단계 입력 흐름과 후원 유형별 필드 노출 로직을 제공합니다.

## 주요 기능

- **단계별 아코디언 UI**: 회원정보 → 후원방법 → 결제방법 → 동의·서명 4단계 진행
- **후원 유형 선택**: 스탠다드, 컨사인(직접입력/지정), 교회·기금정기(일시), 기업후원, 기업 1:1 어린이양육(임직원용 포함) 등 8종 지원
- **유형별 동적 필드 노출**: 선택한 후원 유형에 따라 개인/기업 정보, 이메일 필수 여부 등이 자동으로 조정됨
- **법정대리인 항목 자동 노출**: 만 14세 미만 대상 결연 시 법정대리인 정보 입력란 표시
- **필드 노출 설정 패널**: 유형별로 표시할 필드를 커스터마이징 가능

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 결연서 마크업 및 유형 선택 UI |
| `main.js` | 아코디언 UI, 단계 잠금, 폼 유형별 필드 노출 로직 |
| `style.css` | 스타일시트 |
| `_test.js` | 테스트 코드 |

## 실행 방법

별도의 빌드 과정 없이 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.
